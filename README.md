# Nguyen Anh Duc - CV HTML Templates

## 01-ats-resume
Use this version for Big Tech, enterprise portals and ATS systems.

## 02-portfolio-resume
Use this version when sending directly to HR, technical leads, networking contacts or attaching to your portfolio.

## 03-ats-editorial
ATS-friendly, single-column editorial layout (ruled section headers, left date/title column). An alternative style to 01 — use it when you want a cleaner, more typographic ATS resume.

## Export to PDF
Open `index.html` in Chrome, then:

Print > Save as PDF > Paper size A4 > Background graphics ON.
